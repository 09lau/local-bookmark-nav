# local-bookmark-nav
# 离线本地书签导航 v5
一个独立单HTML书签管理工具，**完全离线运行**，不用服务器、不用数据库，打开html文件就能用。

## 功能介绍
1. 本地存储：所有书签、分类存在浏览器本地，刷新/重启电脑数据不丢
2. 分类管理：新增、编辑、删除分类，自定义图标+主题颜色
3. 书签操作：添加、单删、批量勾选移动/批量删除
4. 实时搜索：顶部输入关键词快速过滤网站
5. 明暗双主题：浅色/深色模式一键切换
6. 导出备份：一键导出完整HTML文件，保存本地永久备份
7. 恢复默认：一键还原自带的基础书签模板

## 使用方法（两种方式）
### 方式1：离线本地使用（推荐，数据只存在你电脑）
1. 下载仓库里 index.html 文件，保存到电脑任意文件夹
2. 双击用Chrome/Edge浏览器直接打开
3. 所有增删改操作自动存在本地浏览器，导出HTML可备份

### 方式2：在线网页打开（GitHub Pages）
打开链接：https://09lau.github.io/local-bookmark-nav/
注意：在线使用数据存在当前浏览器缓存，换浏览器会清空，记得经常导出备份

## 快捷键
- 按 `/` 自动跳到搜索框
- 按 ESC 关闭所有弹窗

## 小提示
1. 管理模式：右上角齿轮图标，开启才能增删改书签分类
2. 导出HTML：管理栏点导出，下载后覆盖原文件永久保存修改
3. 分类可自定义emoji图标、上传图片图标、自定义颜色
4. 7天不再弹出新手指引，可在指引弹窗勾选
